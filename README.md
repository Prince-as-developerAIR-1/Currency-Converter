# Currency-Converter

> A clean, modern, and fast currency converter that supports 30+ world currencies with live exchange rates.

---

## Features

- 30+ currencies (USD, INR, EUR, GBP, JPY, etc.)
- Live Exchange Rates (Free API - No Key Needed)
- Swap Button - Instantly swap FROM and TO
- Auto Convert - Converts as you type
- Clean fintech UI - Black & White Premium Desgin
- Fully Responsive - Works on Moblie & Desktop
- Offline Handling
